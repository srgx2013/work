# 🎯 Herdr — Atajos de Gentleman

> **Prefix**: `Ctrl + A`

---

## 📐 Splits

| Atajo | Acción |
|-------|--------|
| `prefix + v` | Split vertical |
| `prefix + d` | Split horizontal |

---

## 🧭 Navegación (vim-style)

| Atajo | Acción |
|-------|--------|
| `prefix + h` | ← Panel izquierdo |
| `prefix + j` | ↓ Panel abajo |
| `prefix + k` | ↑ Panel arriba |
| `prefix + l` | → Panel derecho |

---

## ↔️ Mover paneles

| Atajo | Acción |
|-------|--------|
| `prefix + shift + h` | Mover izquierda |
| `prefix + shift + j` | Mover abajo |
| `prefix + shift + k` | Mover arriba |
| `prefix + shift + l` | Mover derecha |

---

## 📑 Tabs

| Atajo | Acción |
|-------|--------|
| `prefix + c` | Nuevo tab |
| `prefix + n` | Tab siguiente |
| `prefix + p` | Tab anterior |
| `prefix + 1-9` | Ir a tab # |
| `prefix + shift + x` | Cerrar tab |

---

## 🗂️ Workspaces

| Atajo | Acción |
|-------|--------|
| `prefix + shift + n` | Nuevo workspace |
| `prefix + w` | Workspace picker |
| `prefix + shift + d` | Cerrar workspace |
| `prefix + shift + ←` | Workspace anterior |
| `prefix + shift + →` | Workspace siguiente |

---

## 🔲 Paneles

| Atajo | Acción |
|-------|--------|
| `prefix + z` | Zoom panel |
| `prefix + x` | Cerrar panel |
| `prefix + r` | Modo resize |
| `prefix + Tab` | Siguiente panel |
| `prefix + shift + Tab` | Panel anterior |
| `prefix + \` | Último panel |

---

## ⚙️ Misc

| Atajo | Acción |
|-------|--------|
| `prefix + q` | Detach |
| `prefix + [` | Copy mode |
| `prefix + b` | Toggle sidebar |
| `prefix + ?` | Ayuda |

---

## 🎨 Atajos de Ghostty

| Atajo | Acción |
|-------|--------|
| `Alt + v` | Split vertical |
| `Alt + d` | Split horizontal |
| `Alt + h/j/k/l` | Navegar paneles |
| `Ctrl + Shift + h/j/k/l` | Resize paneles |
| `Cmd + k` | Limpiar pantalla |

---

## 💡 Tips

- `prefix + ?` → ver todos los atajos activos
- `prefix + [` → copy mode (h/j/k/l para navegar)
- `prefix + r` → entrar modo resize, luego h/j/k/l para redimensionar
